# Продуктовые цели Яндекс Метрики

Обе подтверждённые Метрики (`108579634`, `109784590`) получают одинаковый словарь целей через `reachGoal`. Вебвизор и ecommerce `dataLayer` остаются только у `109784590`.

| Цель | Триггер | Основные параметры |
| --- | --- | --- |
| `ticket` | Клик по CTA «Купить билет» | `path`, `location` |
| `dog_open` | Открытие профиля из карточки или избранного | `path`, `dog_slug` |
| `favorite_add` | Добавление животного в избранное | `path`, `dog_slug` |
| `favorite_remove` | Удаление животного из избранного | `path`, `dog_slug` |
| `search` | Поисковый запрос от двух символов после паузы 800 мс | `path`, `query`, `section_slug`, `result_count` |
| `filter` | Выбор или сброс раздела в поиске | `path`, `section_slug`, `action` |
| `section_open` | Открытие породного раздела | `path`, `section_slug` |

События `search` дедуплицируются по сочетанию нормализованного запроса и раздела. UI-тест проверяет, что каждое действие отправляется ровно один раз в каждый счётчик.

В интерфейсе Яндекс Метрики цели с этими идентификаторами должны быть созданы как JavaScript-события. Основной коммерческий KPI — `ticket`; остальные цели описывают путь к нему.
